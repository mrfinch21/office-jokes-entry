A program that writes one original one-line joke about office life to `/output/entry.txt` for make.fun's "Make the AI Judge Laugh: Office Jokes" bounty. The joke: an employee CCs their boss on an email to themself, just so someone in the office would know they exist.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
